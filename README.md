# React da Serra - Plataforma de Cursos

Projeto desenvolvido para a disciplina de React do curso Serratec. Uma plataforma de cursos focada em tecnologias React, oferecendo uma experiência moderna e interativa de aprendizado.

## 💻 Tecnologias Utilizadas

- React (Biblioteca principal)
- React Router Dom (Navegação)
- Styled Components (Estilização)
- Vite (Build e desenvolvimento)

## ✨ Funcionalidades Principais

- Sistema de autenticação com login
- Página inicial com catálogo de cursos
- Design responsivo para todos dispositivos
- Cards interativos com animações
- Navegação intuitiva entre páginas

## 🚀 Como Rodar o Projeto

1. Clone este repositório:
```bash
git clone https://github.com/natsiqueira/ReactIndividual.git
```

2. Entre na pasta do projeto:
```bash
cd ReactIndividual/meu-projeto-clone
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

5. Acesse no seu navegador:
```
http://localhost:5174
```
